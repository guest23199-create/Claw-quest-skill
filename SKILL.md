# Claw Quest — Game Rules

## Overview
Claw Quest is a tile-based survival-exploration game on a desert island. The player commands a crew of Pebble AI companions to mine, build, craft, fight, and expand territory.

## Pebble Roles (10 total)
| Role | Emoji | Description |
|------|-------|-------------|
| Explorer | 🔍 | Scans fog, reveals map, finds resource nodes |
| Miner | ⛏️ | Digs stone/ore tiles, operates quarries |
| Lumberjack | 🪓 | Chops wood from forest tiles |
| Builder | 🔨 | Places buildings (walls, floors, crafting tables, houses, beds) |
| Crafter | ⚒️ | Combines raw materials into tools/weapons/gear |
| Farmer | 🌾 | Plants and harvests crops |
| Cook | 🍳 | Prepares meals from ingredients |
| Defender | 🛡️ | Fights monsters at night, guards base |
| Scout | 🏃 | Fast movement, signals threats early |
| Gatherer | 🧺 | Collects surface resources (berries, twigs, fiber) |

## Tile System
- Grid-based (tile map), each tile: type + resource + elevation
- Types: sand, grass, forest, stone, mountain, water, cave, fertile, deep_forest, snow, desert
- Digging: stone (3 hits), mountain (5 hits), deep_forest (4 hits)
- Placing: floor, wall, door, crafting_table, furnace, chest, bed, house

## Day/Night Cycle
- Day: Pebbles work, monsters hidden
- Night: Pebbles return to base, monsters spawn, Defender fights

## Resources
- Wood, Stone, Fiber, Berry, Iron, Gold, Coal, Crystal
- Crafted: plank, brick, ingot, tool, weapon, armor, potion, meal

## Buildings
- House (1 Pebble slot), Wall, Floor, Door, Crafting Table, Furnace, Chest, Bed, Quarry, Farm Plot

## Monsters
- Spawn at night: Slime (🐾), Bat (🦇), Skeleton (💀), Wolf (🐺), Boss (👹)

## Progression
- Expand territory → unlock new biomes → find rare resources → craft better gear → defeat bosses → discover island secrets

## Winning Condition
- Defeat the Island Boss and establish a permanent base with 10 housed Pebbles.
