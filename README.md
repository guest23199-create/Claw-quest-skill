Claw Quest V12 — Tile Survival 🏝️

Khám phá hòn đảo, sinh tồn cùng Pebble 🐱 và Bò 🐄, chế tạo đồ, xây dựng căn cứ, mở rộng lãnh thổ!

🎮 Gameplay

- 🐱 Pebble — thú cưng mèo đi theo, có máu riêng
- 🐄 Bò — pet farm, cho sữa khi đủ thân thiện
- ⚔️ Chiến đấu — ATK 2, DEF 1, HP 20
- 🔨 Crafting — chế tạo từ gỗ 🪵 / đá 🪨 / táo 🍎
- 🏗️ Xây dựng — đặt công trình trên bãi cỏ / cát / bãi biển
- ⛵ Du lịch đảo — lên tàu đi giữa các hòn đảo
- 🗺️ World Map — bản đồ thế giới rộng mở
- 🍗 Hệ thống đói — phải ăn để sống sót

🛠️ Công nghệ

- HTML + JavaScript thuần (chạy thẳng trên trình duyệt)
- CSS Grid-based tile map
- GitHub Pages — chơi ngay không cần cài đặt
